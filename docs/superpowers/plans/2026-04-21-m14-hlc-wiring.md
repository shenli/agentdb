# M14 HLC Wiring Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Write tests first for each non-trivial step (superpowers:test-driven-development).

**Goal:** Introduce Hybrid Logical Clock (HLC) as AgentDB's clock model. Every event carries an `hlc_ts`; snapshot reads pin an HLC cutoff; Mongo `$clusterTime` and a REST `X-AgentDB-HLC` header propagate causality across the wire; a max-offset guard rejects clearly-bogus inbound timestamps.

**Architecture:** A process-global `HlcClock` (atomic CAS) lives in `agentdb-core` and is referenced by `Box_` (and future `Tablet`). `now()` and `update(remote)` implement textbook HLC (Kulkarni et al., 2014). Events gain `hlc_ts: (physical_ns: u64, logical: u32)`. `ReadCtx` gains `hlc_cutoff`; read paths post-filter by `event.hlc_ts <= ctx.hlc_cutoff`. Max-offset (default 10s) rejects inbound updates whose physical component is further in the future than configured; rejections increment a counter and fail the caller's request.

**Tech stack:** Rust, `parking_lot::RwLock` or raw `AtomicU64`, `tokio`, `axum`, `bson` (Mongo wire).

**Source design:** `docs/agent-db-v2.md` §4 (Clock and consistency), §5.5 (lease + fencing — epoch separate from HLC), §8.2 (metrics).
**Supporting note:** `docs/superpowers/notes/2026-04-21-hlc-clock-decision.md`.

```rust
// crates/agentdb-core/src/hlc.rs

use std::sync::atomic::{AtomicU64, Ordering};
use std::time::{SystemTime, UNIX_EPOCH};

/// Hybrid Logical Clock timestamp. 12 bytes on the wire: 8-byte physical
/// component (nanoseconds since UNIX epoch) + 4-byte logical counter.
#[derive(Clone, Copy, Debug, Eq, PartialEq, Hash)]
pub struct HlcTimestamp {
    pub physical_ns: u64,
    pub logical: u32,
}

impl HlcTimestamp {
    pub const ZERO: Self = Self { physical_ns: 0, logical: 0 };

    pub fn to_u128(self) -> u128 {
        ((self.physical_ns as u128) << 32) | (self.logical as u128)
    }
}

impl Ord for HlcTimestamp { /* lexicographic (physical, logical) */ }
impl PartialOrd for HlcTimestamp { ... }

pub struct HlcClock {
    // Packed representation: high 64 bits are physical_ns >> 32 overflow-safe
    // alternative — but simplest: store physical_ns in high 64 of u128.
    // For atomic CAS, pack into a single u128 via AtomicU64 pair or use a Mutex<HlcTimestamp>.
    // Start: parking_lot::Mutex<HlcTimestamp>. Optimize to lock-free only if
    // benchmark shows contention.
    state: parking_lot::Mutex<HlcTimestamp>,
    max_offset_ns: u64,
}

#[derive(Debug, thiserror::Error)]
pub enum HlcError {
    #[error("inbound HLC physical {inbound}ns exceeds local wall clock {local}ns by more than max_offset {max_offset}ns")]
    OffsetTooLarge { inbound: u64, local: u64, max_offset: u64 },
}
```

- [ ] **Step 2: Implement `HlcClock::now()` (textbook HLC local event)**

```rust
impl HlcClock {
    pub fn new(max_offset_secs: u64) -> Self {
        Self {
            state: parking_lot::Mutex::new(HlcTimestamp::ZERO),
            max_offset_ns: max_offset_secs * 1_000_000_000,
        }
    }

    pub fn now(&self) -> HlcTimestamp {
        let mut s = self.state.lock();
        let wall = wall_clock_ns();
        let phys = s.physical_ns.max(wall);
        let logical = if phys == s.physical_ns { s.logical + 1 } else { 0 };
        *s = HlcTimestamp { physical_ns: phys, logical };
        *s
    }

    pub fn current(&self) -> HlcTimestamp {
        *self.state.lock()
    }
}

fn wall_clock_ns() -> u64 {
    SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .expect("system clock before UNIX epoch")
        .as_nanos() as u64
}
```

- [ ] **Step 3: Implement `HlcClock::update(remote)` (textbook HLC receive)**

```rust
impl HlcClock {
    pub fn update(&self, remote: HlcTimestamp) -> Result<HlcTimestamp, HlcError> {
        let wall = wall_clock_ns();
        if remote.physical_ns > wall.saturating_add(self.max_offset_ns) {
            return Err(HlcError::OffsetTooLarge {
                inbound: remote.physical_ns,
                local: wall,
                max_offset: self.max_offset_ns,
            });
        }
        let mut s = self.state.lock();
        let phys = s.physical_ns.max(remote.physical_ns).max(wall);
        let logical = if phys == s.physical_ns && phys == remote.physical_ns {
            s.logical.max(remote.logical) + 1
        } else if phys == s.physical_ns {
            s.logical + 1
        } else if phys == remote.physical_ns {
            remote.logical + 1
        } else {
            0
        };
        *s = HlcTimestamp { physical_ns: phys, logical };
        Ok(*s)
    }
}
```

## Risk & mitigation

- **Segment format migration.** Mitigation: forward-compat reader (v1 and v2 both work), v2-only writer, tested with fixture v1 segment from prototype data.
- **Mutex contention on HlcClock.** Mitigation: start with `parking_lot::Mutex` (cheap, uncontended case is fast). Only move to lock-free AtomicU128 CAS if a benchmark shows `hlc.now()` in the top-5 contention hotspots.
- **Mongo driver compat.** Mitigation: cross-test with three drivers (Rust mongodb, Python pymongo, Node). One-afternoon spike before Phase E.
