> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `SlateKvStore` as a second `KvStore` implementation backed by object-storage, with `AGENTDB_KV_BACKEND=slatedb` wiring and a MinIO-based smoke script that exercises the S3-backed deployment path.

**Architecture:** New `crates/agentdb-storage/src/slate.rs` sibling of `rocks.rs`, implementing the existing `KvStore`+`KvSnapshot` traits unchanged. `SlateKvStore` owns a dedicated tokio `Runtime` that bridges the sync trait to SlateDB's async API. Server binary picks the backend at startup via env var; a shared `Arc<dyn ObjectStore>` powers both SlateDB's LSM and the existing cold-segment path so one bucket = one config.

**Tech Stack:** Rust, SlateDB (LSM on object storage), `object_store` crate (including `AmazonS3Builder`), MinIO (for opt-in smoke only), `tokio` (dedicated runtime per `SlateKvStore`), criterion (bench extension).

```rust
//! SlateDB-backed `KvStore`. See docs/superpowers/specs/2026-04-19-m11-slatedb-s3-design.md.

use std::sync::Arc;

use object_store::ObjectStore;
use tokio::runtime::Runtime;

use crate::error::{Error, Result};
use crate::kv::{KvIter, KvSnapshot, KvStore, WriteOp};

/// A `KvStore` backed by SlateDB on object storage.
///
/// Owns a dedicated tokio `Runtime` to bridge the sync `KvStore` trait
/// to SlateDB's async API. The runtime runs on one extra OS thread;
/// this was the chosen tradeoff over calling `block_on` on a shared
/// runtime handle (which deadlocks from inside a live tokio task).
pub struct SlateKvStore {
    inner: Arc<slatedb::Db>,
    runtime: Arc<Runtime>,
}

impl SlateKvStore {
    /// Open (or create) a SlateDB database rooted at `path` inside `object_store`.
    /// `path` is an object-store prefix like `"agentdb/slate"` (no leading slash).
    pub async fn open(object_store: Arc<dyn ObjectStore>, path: &str) -> Result<Self> {
        // Adapt per spike output: exact Db::open arg shape may differ.
        let db = slatedb::Db::open(path, object_store)
            .await
            .map_err(|e| Error::Invalid(format!("slatedb open: {e}")))?;

        // Dedicated multi-thread runtime, one extra thread is enough for
        // SlateDB's background compaction + I/O.
        let runtime = tokio::runtime::Builder::new_multi_thread()
            .worker_threads(1)
            .enable_all()
            .thread_name("slatedb")
            .build()
            .map_err(|e| Error::Invalid(format!("slatedb runtime: {e}")))?;

        Ok(Self {
            inner: Arc::new(db),
            runtime: Arc::new(runtime),
        })
    }
}

impl Drop for SlateKvStore {
    fn drop(&mut self) {
        let db = self.inner.clone();
        let rt = self.runtime.clone();
        if let Err(err) = rt.block_on(async move { db.close().await }) {
            tracing::warn!(?err, "slatedb close failed during Drop");
        }
    }
}

// Trait methods implemented in Tasks 4-7. For now the type exists but is not
// `KvStore`; running tests still compile because nothing uses it yet.
```

- [ ] **Step 3: Implement `scan_prefix`**

Replace the stub `scan_prefix` in the `impl KvStore` block with a real
implementation. SlateDB's scan API is most commonly a range scan with
a start+end; for prefix semantics we compute the exclusive upper
bound by incrementing the last byte of the prefix (or extending with
`0xFF` if the prefix is all `0xFF`s):

```rust
    fn scan_prefix(&self, prefix: &[u8]) -> Result<KvIter> {
        let db = self.inner.clone();
        let prefix_vec = prefix.to_vec();
        let upper = next_prefix(&prefix_vec);

        // Eagerly collect the range scan into an owned Vec so the returned
        // iterator is `'static` and doesn't borrow from self or the runtime.
        let collected: std::result::Result<Vec<(Vec<u8>, Vec<u8>)>, _> = self
            .runtime
            .block_on(async move {
                let mut out = Vec::new();
                let mut it = db.scan(prefix_vec..upper).await?;
                while let Some(row) = it.next().await {
                    let (k, v) = row?;
                    out.push((k.to_vec(), v.to_vec()));
                }
                Ok::<_, slatedb::Error>(out)
            });

        let collected = collected
            .map_err(|e| Error::Invalid(format!("slatedb scan: {e}")))?;
        Ok(Box::new(collected.into_iter().map(Ok)))
    }
}

/// Returns `prefix` with exclusive-upper-bound semantics: increment the
/// last byte, carrying through trailing 0xFFs. If `prefix` is empty or
/// entirely `0xFF`, returns a vec representing "unbounded above" via
/// repeated 0xFF extension.
fn next_prefix(prefix: &[u8]) -> Vec<u8> {
    let mut upper = prefix.to_vec();
    for i in (0..upper.len()).rev() {
        if upper[i] < 0xFF {
            upper[i] += 1;
            upper.truncate(i + 1);
            return upper;
        }
    }
    // All 0xFF or empty: push a sentinel beyond any finite key.
    upper.push(0);
    upper
}

#[cfg(test)]
mod prefix_math_tests {

        assert_eq!(next_prefix(&[0x00, 0x01]), vec![0x00, 0x02]);
    }
    #[test]

        assert_eq!(next_prefix(&[0x01, 0xFF, 0xFF]), vec![0x02]);
    }
    #[test]

    }
```

```rust
/// Build the object store chosen by AGENTDB_OBJECT_STORE (`local` default,
/// `s3` opt-in). Performs a best-effort liveness probe after construction.
async fn build_object_store(objects_dir: &std::path::Path) -> anyhow::Result<Arc<dyn ObjectStore>> {
    let kind = std::env::var("AGENTDB_OBJECT_STORE").unwrap_or_else(|_| "local".into());
    let store: Arc<dyn ObjectStore> = match kind.as_str() {
        "local" => {
            std::fs::create_dir_all(objects_dir).context("create objects dir")?;
            Arc::new(
                LocalFileSystem::new_with_prefix(objects_dir).context("open local object store")?,
            )
        }
        "s3" => {
            let bucket = std::env::var("AGENTDB_S3_BUCKET")
                .context("AGENTDB_S3_BUCKET is required when AGENTDB_OBJECT_STORE=s3")?;
            let region = std::env::var("AGENTDB_S3_REGION").unwrap_or_else(|_| "us-east-1".into());
            let mut builder = AmazonS3Builder::from_env()
                .with_bucket_name(&bucket)
                .with_region(&region);
            if let Ok(endpoint) = std::env::var("AGENTDB_S3_ENDPOINT") {
                // MinIO and most S3-compatible deployments need path-style
                // addressing. `allow_http` permits `http://localhost:9000`.
                builder = builder
                    .with_endpoint(&endpoint)
                    .with_allow_http(true)
                    .with_virtual_hosted_style_request(false);
            }
            let s3 = builder.build().context("build AmazonS3")?;
            Arc::new(s3)
        }
        other => anyhow::bail!(
            "unknown AGENTDB_OBJECT_STORE={other}; expected local|s3"
        ),
```

## Observed behavior

- **Startup**: the server performs a `list` probe against the bucket.
  Fails fast with a clear message on bad creds, wrong region, or
  unreachable endpoint.
- **Append latency**: expect +10-30 ms per write versus local-disk

- **Scan latency**: depends on SlateDB's block cache + SST pull. A

- **Cost**: S3 PUTs at scale are not free. For ~1k appends/sec,

  and compaction amortize but don't eliminate.

## Known limitations

- **Snapshot isolation on SlateDB is <TIER per spike>.** <If Tier 3:

- **MinIO gotchas**: MinIO requires path-style addressing and HTTP;
