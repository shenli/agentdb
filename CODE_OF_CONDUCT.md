# Code Of Conduct

AgentDB uses the Contributor Covenant Code of Conduct, version 2.1.

## Our Pledge

We pledge to make participation in this project a harassment-free experience
for everyone, regardless of age, body size, visible or invisible disability,
ethnicity, sex characteristics, gender identity and expression, level of
experience, education, socio-economic status, nationality, personal appearance,
race, caste, color, religion, or sexual identity and orientation.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, but accept responsibility for impact.
- Focus technical disagreement on evidence and tradeoffs.
- Help keep issues and pull requests actionable.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Personal attacks or sustained disruption.
- Publishing private information without explicit permission.
- Sexualized language or imagery in project spaces.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, issues,
and other contributions that violate this Code of Conduct. Repeated or severe
violations may result in a temporary or permanent ban from project spaces.

Instances of abusive, harassing, or otherwise unacceptable behavior may be
reported privately to the maintainer at the address listed on the GitHub profile
for this repository owner.
